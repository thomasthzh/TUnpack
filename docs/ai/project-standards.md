# 实现约定

- 单一 C++20 原生路径；模块按输入视图、解压业务、密码存储、界面拆分，不增加通用框架。
- 复用 bit7z/7z，不重写解压算法，不对业务文件常规计算全量哈希。
- 密码使用 Windows DPAPI 保存，明文只在用户显式输入/导入和运行内存中使用；输出和异常不打印密码。
- 只保留真实文件边界：解压路径不能越出目标、不能经链接写到外部、不覆盖已有内容、失败不清理源包。
- 自动回归不用用户文件。用户已另授权 <CORPUS_ROOT> 真实测试和导入 OnlyUnzip 已有密码导出；真实源全部保留，输出到 <CORPUS_OUTPUT>，密码不显示或另存明文；合成测试数据保留以便复查。
- 子代理最多两个，仅独立只读调研/审查；主代理实施修改。
- 不运行删除用户文件/容器/卷/数据的命令，不生产部署或上传。
- 函数和状态直接清晰；先批量实现相关行为，再跑有意义的集成测试，修复后只扩展必要覆盖。
- 性能与完成声明必须对应当前构建和测量；未覆盖的格式/交互明确记录。
- 恢复工作先读 progress.md/tasks.md，证据与现实不一致时先修正文档。
